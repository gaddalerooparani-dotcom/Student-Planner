# Student Planner

A beginner-friendly student planner web app built with HTML, CSS, and JavaScript.

## Features
- Add tasks with a due date and subject.
- Mark tasks as completed.
- Delete tasks.
- Filter all, pending, and completed tasks.
- View total, completed, and pending task counts.
- Save tasks in the browser using local storage.
- Responsive layout for mobile and desktop.

## How to run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation is required.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
